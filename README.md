# Portafolio con React.js y Bootstrap

## Ejecutar
```bash
npm install
npm run dev
```

```

├── App.css                  # estilos personalizados (morado, tarjetas, botón)
├── main.jsx                 # importa Bootstrap y monta la app
├── data/portfolioData.js    # datos (edita aquí tu info)
└── components/
    ├── Header.jsx
    ├── Intro.jsx
    ├── SkillsSection.jsx  → SkillCard.jsx
    ├── ProjectsSection.jsx → ProjectItem.jsx
    ├── RecommendationsSection.jsx → RecommendationCard.jsx
    ├── LeaveRecommendationForm.jsx
    └── Footer.jsx
```
